PDF Utilities & Document Conversion

Client and server-side utilities to merge, split, rearrange, convert, and manage PDF documents.

Suite Overview

Merge PDFs

Combine multiple disparate PDF files into a single consolidated document with drag-and-drop file ordering.

Split PDFs

Extract specific individual pages or discrete ranges (e.g., 1-4, 7, 10-12) into downloadable standalone files.

Interactive Rearrange

Visual page thumbnail canvas powered by @dnd-kit to reorder, rotate 90°, duplicate, or delete individual pages.

Document Conversion

Convert Microsoft Word (.docx) and images (JPG, PNG) into clean PDF documents, or extract raw text from PDFs.

Asynchronous Job Processing

Large files and complex conversions run asynchronously via background jobs:

  • Progress polling tracking conversion percentage in real time.
  • Temporary files are stored securely in Supabase Storage bucket pdf-jobs.
  • Processed output files generate expiring signed download URLs and are automatically garbage collected after 24 hours.
