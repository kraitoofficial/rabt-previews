Identity Management Supabase Auth

Authentication & Access Control

How identity, sessions, passwordless OTP, and OAuth providers are handled in Rabt v3.0.0.

Supported Authentication Methods

Rabt leverages Supabase Auth via @supabase/ssr, featuring seamless server-side cookie refresh and token rotation in the Next.js 16 Proxy layer:

Email OTP & Magic Link

Primary passwordless login method. A 6-digit numeric verification code is dispatched to the user’s email for zero-password secure authentication.

Social OAuth Providers

Instant single-click sign in supporting Google Workspace and Facebook OAuth configured through the Supabase Authentication Dashboard.

Zero-Password Security

Eliminates credential leaks and password reuse risks. Access is strictly authenticated via cryptographically secure single-use codes and tokens.

Initial Super Admin Promotion

For zero-trust security, every new registration defaults to the restricted User role. To establish your initial platform owner, sign up via the app and promote your profile in the Supabase Dashboard SQL Editor: 

UPDATE public.profiles
SET role = 'Super Admin', is_verified = true
WHERE email = 'admin@yourcompany.com';
Administrative Alerts: The DB_ADMIN_EMAIL environment variable designates the recipient address for payment reminders, system logs, and notification emails. It does not automatically escalate account permissions.

Profile Completion Guard

When a new user signs up or logs in via OAuth for the first time without a populated full name or contact details, the ProfileCompletionGuard intercepts the route and guides the user to complete their workspace profile before continuing.

Supabase Auth Email Branding & Templates

Authentication emails (magic links, signup confirmations, user invitations, and email changes) are sent through Supabase Auth. To ensure your users receive emails consistent with your brand:

  1. Custom SMTP: In your Supabase Dashboard → Project Settings → Authentication → SMTP Settings, enable Custom SMTP and set:
    • Sender Name: Your company or brand name (e.g. Acme Corp).
    • Sender Email: Your company sender address (e.g. noreply@yourdomain.com).
    • Host / Port / Credentials: Matching your application's SMTP_* configuration.
  2. Passwordless HTML Templates: Pre-styled, mobile-responsive HTML email templates matching Rabt's brand identity are provided in the repository under supabase/email-templates/:
    • magic-link.html → Magic Link template (instant sign-in button & OTP code)
    • confirmation.html → Confirm signup template (email activation)
    • invite-user.html → Invite user template (workspace onboarding)
    • change-email.html → Change Email Address template (email verification)
    In your Supabase Dashboard → Authentication → Email Templates, simply copy and paste each template's HTML content into the corresponding tab.

Proxy Level Session & ACL Protection

In Next.js 16, Rabt uses proxy.ts to inspect every request before page rendering:

  • Session Validation: Decodes and validates JWTs against Supabase Auth.
  • Automatic Token Refresh: Refreshes expiring cookies transparently without client-side redirect flashes.
  • Fail-Secure ACL: Prevents unauthorized roles from loading admin dashboards or triggering mutation endpoints.
