Supabase Storage Staff, Admin, Super Admin

Cloud File Storage & Asset Management

Secure enterprise file repository powered by Supabase Storage with role-based folder isolation.

Storage Architecture

Files in Rabt v3.0.0 are uploaded directly to the files storage bucket in your Supabase project. Database records in the files table track ownership, file tags, byte sizes, and MIME types.

Signed URLs

Files are protected behind private bucket policies. Downloads generate time-expiring signed tokens to prevent unauthorized hotlinking.

Smart Categorization

Filter by Documents, Invoices, Contracts, Receipts, and Images with custom metadata tags for rapid discovery.

Full-Text Search

Instant client-side and database-backed searching across filenames, extensions, and descriptive user tags.

Supported File Types & Limits

Category Permitted Extensions Maximum Size
Documents .pdf, .docx, .xlsx, .txt 50 MB per file
Images .png, .jpg, .jpeg, .webp, .svg 25 MB per file
Archives .zip, .tar.gz 50 MB per file

Security & Scoping

  • MIME Sniffing Prevention: Strict server-side content-type verification prevents malicious script execution.
  • Safe Area Isolation: Files are stored with cryptographic UUID prefixes to eliminate collision risks.
  • Role Scoping: Super Admin and Admin users can access all assets; Staff users are restricted to organization-level files.
