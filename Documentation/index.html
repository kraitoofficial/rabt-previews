Supabase Backend Next.js 16 + React 19 Bun 1.4+

Unified CRM, Inventory, Billing & File System

Rabt v3.0.0 delivers an ultra-fast, modern workspace built on Next.js 16 (Turbopack), Supabase Postgres, Supabase Auth, Supabase Storage, and Tailwind CSS v4. Manage directory contacts, sales pipelines, inventory stock, branded invoices, and PDF utilities from a single responsive interface.

Core Modules

Contact Directory

Centralized business contacts with hierarchy, one-click vCard download, interactive QR codes, WhatsApp/call links, and search facets.

Lead Pipeline

Track sales opportunities through custom stages (New, Contacted, Qualified, Proposal, Won, Lost), priority tags, activity logs, and bulk actions.

Invoices & Billing

Generate professional PDF invoices with automatic inventory deduction, tax/discount calculations, SMTP email delivery, and public QR verification.

Inventory Tracking

Manage product catalog and services with SKU tracking, buy vs sell margins, minimum threshold alerts, and real-time stock activity logs.

Cloud File Storage

Secure file management powered by Supabase Storage bucket files, with role-based folder access, tagging, and preview capabilities.

PDF Utilities

Server-side and client-accelerated PDF tools: Merge multiple PDFs, Split by page ranges, Rearrange with drag-and-drop, and Convert DOCX/Images.

Architecture & Tech Stack

Layer Technology Description
Framework Next.js 16.4+ + React 19 App Router, Server Actions, Turbopack, standalone Docker output
Runtime & Tools Bun 1.4+ / Node.js 20+ Ultra-fast package installation, build scripts, and execution
Database Supabase (PostgreSQL 15+) Relational schema, row-level security (RLS), atomic stock reduction RPCs
Authentication Supabase Auth (@supabase/ssr) Passwordless OTP, Magic Links, OAuth (Google/Facebook), proxy session refresh
Storage Supabase Storage Buckets: branding, files, invoices, pdf-jobs
Styling Tailwind CSS v4 + OKLCH Modern Zinc palette, seamless Dark & Light theme, custom design tokens
PDF Engine Puppeteer + pdf-lib + pdfjs-dist Pixel-perfect HTML-to-PDF invoice rendering with fallback support
Email Transport Nodemailer (SMTP) Send invoice PDFs, payment receipts, and automated payment reminders
