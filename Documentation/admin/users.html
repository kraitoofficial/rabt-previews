User Management & Role Assignment

Administer registered workspace users, inspect authentication statuses, and assign operational privileges.

User Table & Metadata

The User Management panel at /admin/users provides complete visibility over team accounts:

  • Display Name & Avatar: Profile identity synchronized from user input or social OAuth profile pictures.
  • Email & Verification: Displays whether the user email has been verified via OTP or Supabase Auth.
  • Assigned Role: Current access tier: Super Admin, Admin, Staff, or User.
  • Activity Timestamps: Creation date and last active session timestamp.

Modifying User Roles

Role modifications take effect immediately across all active sessions:

Super Admin Privilege: Only users with the Super Admin role can promote or demote other users to or from Admin/Super Admin status. Standard Admins can assign Staff and User roles.

User Deactivation & Access Revocation

Admins can toggle the active status of any team member. Deactivating a user immediately invalidates active Supabase session tokens and prevents subsequent login attempts.
