Rabt Features & Capabilities

Comprehensive overview of all core modules, business utilities, security controls, and workflow automations.

6 Core Modules
4 RBAC Roles
100% Supabase Native
PWA Mobile Ready

1. Contact Directory

The Contact Directory serves as your organization’s unified phonebook and relationship database. It offers deep metadata, hierarchy, and quick communication actions:

  • vCard 3.0 Export: Instant one-click generation and download of .vcf files to import directly into Apple Contacts, Google Contacts, or Outlook.
  • Interactive QR Code: Generate instant scannable vCard QR codes to share contact details with clients and visitors in seconds.
  • Direct Communication Triggers: Embedded action buttons for direct phone dialing (tel:), WhatsApp instant messaging with prefilled numbers, and default email client launch.
  • Organization Hierarchy: Categorization by department, designation, and primary company with search facets and instant filtering.
  • Batch Operations: Import contacts via CSV/Excel and execute bulk deletion with dependency verification.

2. Lead Management & Sales Pipeline

Track prospective deals and customer acquisitions through an intuitive pipeline view with comprehensive activity tracking:

  • Pipeline Stages: Progress leads from New → Contacted → Qualified → Proposal → Won or Lost.
  • Priority Categorization: Flag leads with Low, Medium, High, and Urgent visual badges.
  • Activity Logging: Full historical audit trail recording every call, status transition, priority adjustment, and team note.
  • Bulk Management: Select multiple leads to batch-update stages, assign account representatives, or execute batch deletion.
  • Pipeline Analytics: Real-time conversion metrics, deal volume by status, and win/loss percentages.

3. Invoicing, Billing & Verification

End-to-end billing cycle management tightly coupled with inventory control and automated delivery:

  • Live Inventory Lookup: Select items directly from inventory; prices, units, and SKU information populate automatically.
  • Automated Stock Reduction: Finalizing an invoice executes an atomic Postgres RPC to immediately decrement warehouse inventory.
  • PDF Generation Engine: Headless Chromium (Puppeteer) produces pixel-perfect print-ready PDFs, with fallback to lightweight pdf-lib rendering.
  • Direct SMTP Email Delivery: Send invoices directly to the client’s email with the PDF attached using customizable HTML email templates.
  • Public Invoice Verification (QR Code): Every invoice includes an encrypted QR code linking to /verify/invoice for instant authenticity checks without requiring login.
  • Automated Reminders: Automated cron target (/api/cron) checks due dates and triggers polite email reminder sequences.

4. Inventory & Stock Control

Complete visibility over physical products, digital items, and service offerings:

  • Stock & Service Tracking: Separate trackable inventory goods from intangible professional services.
  • Margin Analytics: Maintain separate buy price (cost) and selling price (MSRP) to calculate profit margins.
  • Low Stock Threshold Alerts: Set minimum stock quantity warnings to trigger reorder notifications before running out.
  • Stock Movement Logs: Detailed log entry for every manual stock adjustment, return, and automated invoice deduction.

5. Cloud File Storage

Enterprise document management built directly on top of Supabase Storage bucket files:

  • Smart Categorization: Automatically organize files under Documents, Invoices, Contracts, Receipts, and Images.
  • Role-Based Access: Folder scoping ensures users only access files permitted by their RBAC permission level.
  • Secure Previews & Signed URLs: Streamlined previewing of PDFs and images with time-expiring signed download URLs.
  • Tagging & Search: Add custom metadata tags and execute full-text search across all uploaded media.

6. PDF Utilities Suite

Client and server-side document workflows without third-party external dependencies:

  • PDF Merge: Combine multiple PDF files into a single consolidated document with custom sequence order.
  • PDF Split: Extract single pages or discrete page ranges (e.g., 1-3, 5, 8-10) into separate files.
  • Drag-and-Drop Rearrange: Visual page grid powered by @dnd-kit to drag, reorder, rotate, duplicate, or delete individual pages.
  • Document Conversion: Convert Microsoft Word (.docx) documents and images (JPG, PNG) into clean PDF documents, or extract text from PDFs.
  • Job Queue: Background asynchronous processing for large files with visual progress bars.

7. Administration, RBAC & Security

Granular controls for administrators to tailor the platform:

  • Proxy-Level Access Control: Next.js 16 Proxy (proxy.ts) enforces session validation and role authorization before routes render.
  • 4 Tier Hierarchy: Super Admin, Admin, Staff, and User.
  • Secure Super Admin Bootstrap: Initial registrations default to the User role by security design; elevate your initial administrator securely via Supabase SQL Editor on public.profiles.
  • Branding Customization: Upload dark and light logos, configure custom browser favicon, and adjust organization legal details.
  • System Audit Logs: Tamper-evident record of security actions, user logins, configuration changes, and data modifications.
